# Windows nativo com escopo inicial explícito

O contrato aprovado acrescenta Windows 11 x64 ao suporte existente de Ubuntu/GNOME/Wayland, com os mesmos Módulos e diferenças de capacidade explícitas. O mínimo exige as integrações de IA, Agentes, GitHub e Tarefas, Rede e Sistema com suas métricas básicas; temperatura, tráfego por processo e detalhes avançados sem equivalente validado podem aparecer como indisponíveis. Esse recorte permite uma implementação sem componente privilegiado e evita prometer paridade com coletores Linux antes de verificá-la.

No Windows, a primeira cobertura de Agentes é dos CLIs Codex e Claude Code nativos com execução local viva, preservando os Estados da sessão existentes. WSL, sessões exclusivas de apps/IDEs e tarefas persistidas sem processo ficam para ampliação posterior. Hooks dependem de conexão explícita, com consulta periódica como alternativa; notificações nativas com clique abrindo Agentes integram o mínimo. A status line Claude é obrigatória, enquanto seu OAuth opcional pode ficar indisponível no Windows até adaptação e validação próprias.

Credenciais pertencem ao Windows Credential Manager com persistência restrita ao usuário e à máquina, sem roaming; Ubuntu mantém GNOME Keyring. Um backend simulado ou armazenamento alternativo em arquivo não satisfaz esse contrato, e a ausência de cofre real impede salvar. O detalhamento do mínimo e de sua distribuição está em [Qual é o mínimo obrigatório do produto no Windows?](../../.scratch/jira-windows/issues/05-windows-minimum.md); esta decisão não comprova implementação nem execução já validadas.

Rede no Windows mede os contadores de uma interface, escolhida pela rota para o destino da sonda. Essa leitura evita duplicação ao atravessar interfaces virtuais. Testes de velocidade exigem que o Windows informe conexão à internet e custo irrestrito. O cache guarda um identificador opaco da rota, com endereços mantidos em memória. Segurança da rede e tráfego por aplicativo aparecem como indisponíveis até terem fontes validadas.

Sistema lê CPU, RAM, discos fixos e bateria pelas APIs do Windows. A interface diferencia ausência de bateria de erro de leitura, explica a indisponibilidade de temperatura e reserva o rótulo Swap à métrica Linux. Os dois coletores reiniciam as amostras após suspensão mesmo quando o computador retoma sem internet.
